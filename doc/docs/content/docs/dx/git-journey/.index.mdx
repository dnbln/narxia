This is a guide to understanding how guides in the Narxia documentation are built.
We use a custom tool, called `git-journey`, to generate (some of) these guides.

`git-journey` is a tool that allows us to create guides that are based on the Git
history of a project. The way it works is that we have a file called `source`,
around which we will build our guide. We commit multiple times to this file,
for every step of the guide. Each commit will contain a small change to the file,
and the commit message will describe the change.

Part of the commit message can contain text with the `git-journey-pre:` and
`git-journey-post:` headers, which will add the corresponding text to the generated
guide, before and after the `source` file, respectively.

Here we will go over what `git-journey` actually does, and how to use it.

# So why does it exist?

Guides can sometimes be hard to maintain, especially when they are based on code
examples that change frequently. Sometimes those changes have to be repeated
for the subsequent blocks of the guide, which can lead to a lot of repetitive code.

This is where `git-journey` comes in. It allows us to create guides that are
based on a Git history of some file, which we call `source`. The `source` file
is a file that contains the code examples that we want to show in the guide.

We can commit to this file multiple times, each time adding a small change to it,
and the commit message will contain the text that we want to show in the guide,
around the code. Now, whenever we want to update the guide, we find the commit
corresponding to the first version of the file where we can make the change we
want to make, and we can do a rebase starting from that commit. This allows us
to avoid repeating the changes for all subsequent blocks in the guide, and we
can just focus on the changes that we want to make.

The guides are maintained as separate branches in the repository; to update a guide,
you should first check out the branch corresponding to the guide you want to update,
and then rebase, and edit the history.
