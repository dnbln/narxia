This is the index page for the Narxia language compiler documentation. This is intended for developers of the compiler, rather than users of the language. For user documentation, see [the user-docs](../user/index.mdx).

Below is a table of contents:

- [Parsing](./parsing.mdx): Documentation regarding parsing of the source code.
- [Syntree](./syntree.mdx): Documentation regarding the syntax trees produced by the parser.
- [HIR](./hir.mdx): Documentation regarding the High-level intermediate representation used by the compiler.
- [Call graph analysis](./call-graph-analysis/problem-statement.mdx): documentation about the call graph analysis algorithm used in the compiler for functionality partitioning.
